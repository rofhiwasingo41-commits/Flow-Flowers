# Flow Flowers  ST10437465 Rofhiwa Singo
A simple multi-page website for **Flow Flowers**, a flower shop based in Polokwane, South Africa.  
The site showcases the shop’s story, flower types, contact details, and enquiry forms.

##  Features

-  Homepage with business overview and quick navigation.  
-  About Us page describing Flow Flowers’ story and mission.  
-  Flower Types page with detailed descriptions and care tips.  
-  Enquiry form for general questions.  
-  Contact page with email, phone, address, and a contact form.
- Dynamic Content: The footer on all pages displays the current time and date, which updates every second (real-time clock).
- Flower Search Filter: The Plant Types page includes a search bar to dynamically filter flower guides based on text input.
- Accordion Menus: Content on the About Us page is organized into collapsible sections for improved user experience.
- Form Validation: Client-side JavaScript is used to validate input fields on both the Enquiry and Contact forms, providing user feedback and preventing submission on error.
- SEO Implementation: All HTML pages include unique <meta name="description"> and <meta name="keywords"> tags to improve search engine categorization.
- Social Media Links: The footer contains icons linking to Facebook, Instagram, and WhatsApp.
- Embedded Maps: Google Maps are embedded on the Contact and About Us pages to show physical locations.
